Prós de Usar o Eclipse

  • Ambiente robusto para aplicações JAVA EE, diversas funcionalidades
  • Suporte ao GIT nativo, com ressalvas
  • Suporte a extensões e agentes de IA
  • Padronização Corporativa
  • Consolidação no mercado

Contras de Usar o Eclipse

Interface não amigável para usuário iniciante

Pesado e menos fluido para atividades simples, a exemplo de uma POC

Limitação a extensões de desenvolvimento para web moderno

Auto complete não nativo para html, somente após integração com Plugin

Alguns bugs após alterar o tema do sistema

Ex.: Fechou o projeto automaticamente após realizar a troca do theme de DARK para Classic

GIT embutido, porém de difícil usabilidade
